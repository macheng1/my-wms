# 小程序信息审核管理 PRD（管理端）

## 目标

平台管理员在 B 端维护小程序首页分类、分类发布模板、轮播图，并审核用户发布的信息。

## 本期页面

### 分类管理

- 字段：分类名称、分类图片、跳转 URL、发布字段模板。
- 发布字段模板使用 JSON 数组维护，保存到后端 `templateFields`。
- 支持新增、编辑、删除、启停。

### 信息审核

- 入口：小程序管理 / 信息审核。
- 表格字段：状态、标题/分类、发布人、企业认证标识、手机号、地区、浏览数、发布时间。
- 搜索项：关键词、状态、地区。
- 操作：通过、驳回、下架。
- 驳回/下架时支持填写原因，保存到 `auditRemark`。

## 权限

- 菜单权限码：`platform:miniapp:post:list`。
- 当前按平台管理员角色授权。

## 验收标准

- 能在菜单看到“信息审核”。
- 默认进入待审核列表。
- 审核通过后，小程序公开列表可见。
- 驳回后，小程序我的发布可看到驳回原因。
- 分类模板保存后，小程序发布页可动态展示对应字段。
