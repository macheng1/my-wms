# 前端测试验证

## 使用目标

证明管理端页面可构建、可访问、可操作，并且与后端接口契约一致。

## 验证流程

1. 根据改动范围选择验证方式。
2. 优先运行：
   - `pnpm run lint`
   - `pnpm run build`
3. 页面改动启动 dev server，并用浏览器检查关键页面。
4. 接口改动验证请求路径、参数、返回结构和错误处理。
5. 权限/菜单改动验证菜单可见性、路由访问和无权限状态。

## 检查清单

- 页面是否能正常打开。
- 控制台是否有错误。
- 表格是否能加载、分页、筛选、刷新。
- 表单是否能校验、提交、回显。
- loading、empty、error 状态是否完整。
- 删除和状态切换是否有确认。
- API 错误是否走统一 Toast。
- 移动/窄屏下是否有明显布局溢出。

## 汇报要求

- 说明执行了哪些命令。
- 说明浏览器验证的页面和结果。
- 说明未覆盖的联调项和原因。
